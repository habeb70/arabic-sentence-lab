# Arabic Sentence Lab | معمل الجملة العربية

Eight offline exercises for learners of Modern Standard Arabic. Practise word order and verb tense with English clues, Arabic feedback and model answers.

## Get started
Download and extract the repository ZIP, then open index.html in a browser. Choose a mode, type an answer, and select تحقّق. Select اعرض إجابة نموذجية to see a model answer. No installation is required.

## Add exercises
In index.html, add a row to the order or tense list inside lessons. Each row contains an Arabic prompt, English clue, model answer and optional accepted variants. Test each variant locally before contributing.
